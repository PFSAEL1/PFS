# PFS Filters for agents

PFS Filters (https://www.pfsfilters.com) sells paint booth and spray booth filters online. It is the filter division of PFS Spray Booths, 1400 Airport Blvd, Santa Rosa, CA 95403, United States. Phone: 855-496-7969.

This file describes how to read the catalog. It does not place orders. There is no automated checkout in this file.

## Read the catalog

- Product JSON: https://www.pfsfilters.com/products.json
- Human catalog: https://www.pfsfilters.com/shop
